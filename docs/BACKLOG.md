# Заготовки GitHub Issues

Это локальный backlog, его можно переносить в Issues. Каждый пункт — отдельная узкая задача, с явной проверкой, а не огромный запрос «сделай игру».

## ISSUE-01 · Показать сенсоры и данные, которые реально доступны роверу
**Приоритет:** ближайший. **Идеи:** LP-007/008/032.
**Готово, когда:** можно посмотреть последнее наблюдение лидара, освещённость, температуру, заряд, направление; агент физически не может прочесть скрытые тайлы; тест доказывает ограничение.

## ISSUE-02 · Строгая энергетическая и термальная модель
**Идеи:** LP-004/005/006/041.
**Готово, когда:** на фиксированном seed и шаге есть тесты затрат на движение/анализ/датчики, прогрев, полное отключение и пробуждение строго при 70%; полярная физика отделена от ускоренного игрового пресета.

## ISSUE-03 · Модель данных, забывания и возвращения
**Идеи:** LP-009/010/011.
**Готово, когда:** отдельные RAM, накопитель карт, журнал, модель; при заполнении карта действительно забывает тайлы, а навигация меняется; проверяется невозможность точного возврата при потере ориентиров.

## ISSUE-04 · Воспроизводимый эксперимент и сохранения
**Идеи:** LP-031/032.
**Готово, когда:** seed + версии + конфиг + действия позволяют воспроизвести трассу; сериализация имеет версию; есть тест round-trip.

## ISSUE-05 · Обучение первой задаче навигации
**Идеи:** LP-012/013/028/033.
**Готово, когда:** есть обучаемая политика и baseline, тренировка + независимый набор seeds + честные метрики; реальный прогресс или честно зафиксированный провал.

## ISSUE-06 · Первая зарядная точка
**Идеи:** LP-017/018/021.
**Готово, когда:** материал/кабель/панель/энергопотери из физических запасов, реальное размещение и зарядка без телепортации.

## ISSUE-07 · Реестр экспериментов и режимы наблюдения
**Идеи:** LP-030/031.
**Готово, когда:** можно открыть предыдущие попытки, сравнить графики энергии/памяти/дистанции, ускорить выполнение без изменения физического результата.

## ISSUE-08 · Информационный узел и бэкап
**Идеи:** LP-015/016/019/020.
**Готово, когда:** данные передаются только по доступной связи, занимают ёмкость, расходуют энергию, могут быть потеряны.
