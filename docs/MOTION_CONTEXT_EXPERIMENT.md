# Опыт короткой памяти движения · LP-010/043

## Гипотеза и критерий до запуска

После аудита живого обучения владелец согласовал следующий узкий шаг: дать сети ограниченную историю собственных действий и их измеренных последствий. Гипотеза: текущий снимок неоднозначен, а история поможет различать исследование и длительное вращение. Это ещё не установленная причина деградации.

Окно — последние 32 активных действия (64 секунды работы при шаге 2 s). Запись содержит только приращения одометрии, поворот, выбранное действие, контакт, новые пространственные данные, расход энергии и факт свежего скана. Бюджет — 1 KiB логических Float32-данных, отдельно от карты, весов и replay. Во время спячки окно не обновляется; это история активной работы, а не последних 64 секунд мирового времени. LAB-reset очищает окно, сохраняя обучаемую модель, replay и отложенный отказ.

Двенадцать признаков: заполненность окна, длина пути, модуль смещения, суммарный подписанный поворот, доли поворотов/движения/ожидания/проб, доля контактов, новые данные, расход энергии и доля свежих сканов. Они вычисляются из доступных показаний; истинные координаты и диагностика застоя не поступают в сеть. Награда прежняя, команды «выехать из застоя» нет. Обработка входит в существующий LAB-бюджет CPU 2.2 W, обучение — дополнительно 4 W; оценка процессорной мощности остаётся приближением.

## Совместимость

Отдельный опыт `motion-lab-v1`, политика `motion-dqn-v1`, schema 4, сеть 61→32→5. Явный перенос 49→61 обнуляет новые связи и сохраняет исходные прогнозы. Старые модели и сохранения не переименовываются. Replay ограничен 512 переходами (около 252 KiB логических данных), смешанная схема 256 недавних + 256 исторических одинакова у обоих сравниваемых вариантов. Короткое окно не сохраняется при экспорте только весов. Сводка UI остаётся schema 4 с отдельным ID опыта.

## Протокол motion-context-v1

- Исходный мозг: комплектный `curiosity-dqn-v1`, E125261.
- Два тренировочных seed: 1601 и 2909. По 80 эпизодов, 2400 шагов; карты 12001–12016, одинаковое расписание exploration 0.65→0.06.
- Две группы с одинаковой архитектурой/наградой/replay/бюджетом: `context` видит историю, `masked` получает нули вместо её 12 входов. Перенос до обучения — отдельный контроль `initial`.
- Проверка после обучения на картах 13001–13003, learner seed 101 и 907. Для каждой пары: шесть LAB-reset по 2400 шагов и отдельная жизнь 43200 шагов (24 симулированных часа) без reset.
- Выбор одного checkpoint внутри каждой группы: меньше окон застоя/вращения, затем больше посещённых клеток в последних трёх reset, затем меньше отключений и столкновений. Порог окна прежнего аудита: 300 шагов, ≥100 активных действий; вращение — путь <1 m и ≥70% поворотов; застой — путь <1 m, <5 новых наблюдений и ни одной новой посещённой клетки. Это внешние метрики, не входы и не награда.
- После фиксации выбора: только один test на картах 14001–14004, learner seed 103 и 919. Сравнить выбранные `context`, `masked` и `initial`. Карту 4233 допустимо посмотреть отдельно лишь для диагностики, не выбирать по ней веса.

Критерий продвижения в основной режим: на validation и test у `context` меньше плохих окон, чем у `masked` и `initial`, без снижения среднего покрытия/посещения в непрерывной жизни и без роста отключений/столкновений. Иначе оставить отдельным LAB-опытом и зафиксировать отрицательный или смешанный результат. Поиск кандидата пласта учитывается, но не объявляется освоенным по росту покрытия.

Полные журналы локальны; в Git сохраняются модели выбранных групп, протокол, seed, метрики всех запусков и SHA-256 исходников/моделей. Время/карты прежних тестов не используются для настройки этого опыта.

## Результат

Завершён 17.10.2026: четыре тренировки / 320 эпизодов и 54 сценария живой проверки, всего **3 878 400 шагов**. По заранее заданному сравнению validation выбраны `context-2909` (E163378) и `masked-2909` (E163254). Выбор сохранён до открытия test. Исходный контроль — явный перенос E125261.

Вращение и застой могут пересекаться. История снизила столкновения, но уступила замаскированному контролю по общему застою, вращению, покрытию и части отключений. **Гипотеза полезности этого контекста не подтверждена.** Это результат конкретного окна/представления, двух тренировочных seed и текущего алгоритма; он не доказывает бесполезность памяти вообще. Улучшение относительно исходного переноса нельзя приписать новым признакам: контроль без доступа к ним оказался лучше. Награда, состав опыта и горизонт оценки будущих последствий остаются отдельными причинами для проверки.

Основной профиль не заменён. «Память движения · LAB» доступна отдельно, с честной телеметрией пути/смещения и результатом сравнения. В браузере кнопка обучения продолжает текущие веса с одним тренировочным seed и сравнивает их с исходными для этого нажатия на живой validation; это интерактивный LAB, не новое независимое исследование. Канонический сравнительный запуск — `npm run train:motion`.
