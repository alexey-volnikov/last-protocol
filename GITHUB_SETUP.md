# Перенос проекта на GitHub

На момент первоначальной подготовки проекта новый удалённый репозиторий **ещё не создан**. Локальная копия уже является Git-репозиторием с первоначальным коммитом.

1. Открыть https://github.com/new .
2. Owner: `alexey-volnikov`; имя: `last-protocol`.
3. Рекомендуется **Private** на стадии экспериментов, публичность выбрать позже.
4. **Не добавлять автоматически** README, .gitignore или лицензию: они уже в архиве/локальном Git.
5. Создать репозиторий на GitHub и в папке проекта выполнить:

```bash
git remote add origin https://github.com/alexey-volnikov/last-protocol.git
git push -u origin main
```

Если имя репозитория изменено, изменить URL remote соответственно.

Требуется GitHub-аутентификация на машине, с которой выполняется `git push`. Не помещать PAT/секреты в чат или в Git. Если GitHub подключён к ChatGPT, после создания пустого репозитория помощник может наполнять его через доступные GitHub-инструменты с отдельным подтверждением фактических операций.
