# LAST PROTOCOL · Последний протокол 🌕

**Открытая лаборатория автономной лунной жизни.** Один маленький ровер, посадочная капсула, процедурная поверхность Луны, ограниченные энергия и память, сенсоры, ошибки и обучение. В перспективе — сеть энергетических/информационных узлов, геология, добыча воды и несколько независимых ИИ.

> **Статус: ранняя лаборатория `0.3.1`.** Исправлена слепая зона лидара у близких краёв камней. В независимом сравнении меньше столкновений, но немного больше застоя и ниже покрытие; устойчивый объезд не освоен. В UI — счётчик контактов и последнее показание по курсу. Протокол и ограничения — [`docs/LIDAR_CORRECTION.md`](docs/LIDAR_CORRECTION.md). Нейросеть выбирает действия сама; готового маршрута к пласту нет. Прежние опыты и их результаты сохранены.

## 🚀 Попробовать прототип

1. Скачайте репозиторий или распакуйте архив.
2. В корне запустите `npm run dev` (Node.js 22+). Сервер отдаёт актуальные модули без устаревшего кэша, в том числе на Windows; установка пакетов не нужна. Для просмотра готовой копии допустим и `python -m http.server 8000 --bind 127.0.0.1`.
3. Откройте `http://localhost:8000` в браузере.
4. В новом браузере открыта «Далёкий пласт · любопытство», затем запоминается выбранный опыт. Для плавного наблюдения выберите 1×–20×, для ускоренной проверки — 100×–500×. Смотрите новые данные последнего скана, оценки неизвестного по направлениям, журнал проб и время работы/спячки. Столбики показывают прогноз из памяти, не скрытую поверхность. «Истина (dev)» показывает пласт человеку; мозгу эта карта недоступна. Первая льдинка не останавливает экспедицию.
5. В блоке «Мозг и эксперимент» можно выбрать «Разведка · версия 2», прежнюю память движения, мозг разведки или малый тест, выключить обновление весов или запустить обучение. Мозг каждого из пяти опытов хранится отдельно. Версия 2 связывает результат действия с показаниями следующего реального решения; LAB показывает путь, смещение и результат последних 32 активных действий. LAB-сброс и обновление страницы начинают новый мир: **полного сохранения экспедиции пока нет**. Для тестов: `npm test`; для нового сравнения: `npm run train:sequential`; для прежнего: `npm run train:motion` / `npm run train:curiosity` / `npm run benchmark:curiosity`. Старые команды `train:deposit` / `train:water` сохранены.

Повороты и движение корпуса теперь интерполируются между физическими шагами. Для спокойного наблюдения подходят 1×–20×; на 1000× отдельные действия происходят быстрее экранных кадров. Это сглаживание не меняет решения сети или физику.

В 0.3.1 новый лидар применяется ко всем мозгам без изменения формата весов. Его старые показания между оплаченными сканами могут устареть. Для воспроизводимого сравнения: `npm run benchmark:lidar`; диагностика известного дефекта: `npm run diagnose:lidar`. Test: 69 столкновений против 85 со старым прибором, проблемных окон 24 против 22, среднее покрытие за жизнь 87.1 против 95.1 посещённых клеток. Полный критерий улучшения не выполнен. Приведённые ниже прежние benchmark-цифры относятся к указанным версиям до исправления прибора, а не к 0.3.1.

Сборщиков, внешних библиотек и API-ключей не нужно. Для открытия модулей нужен только локальный HTTP-сервер; модель и обучение исполняются на компьютере.

Первый результат любопытства на 16 новых картах: в среднем **521 наблюдённая и 43 посещённые клетки** против 233 и 10 до обучения. Отключений 13 против 12, столкновений больше, кандидатов пласта 0/16. Это прогресс покрытия с ухудшением части показателей безопасности; безопасная разведка ещё не освоена.

**Проверка живого обучения после сообщения о вращении:** прежние цифры относятся к замороженной модели. Аудит 72 сценариев воспроизвёл деградацию при дальнейших обновлениях и нашёл потерю отложенного отказа при LAB-сбросе. Учёт отказа исправлен; он не гарантирует устранения вращения. Смешанная память дала частичное улучшение в отдельном LAB-контроле с ухудшением части метрик. Подробности и команды — в [`docs/ONLINE_LEARNING_AUDIT.md`](docs/ONLINE_LEARNING_AUDIT.md).

**Следующая проверка — память последних действий:** отдельный LAB с окном 32 действия / 1 KiB RAM действительно передаёт сети измеренное движение и последствия. Четыре тренировки и 54 сценария не подтвердили пользу выбранного контекста: test 36 проблемных окон против 29 без доступа к истории, посещено за сутки 60.4 против 91.4 клетки, кандидатов пласта нет. Он доступен отдельно и не заменяет основной мозг. Протокол и ограничения — [`docs/MOTION_CONTEXT_EXPERIMENT.md`](docs/MOTION_CONTEXT_EXPERIMENT.md). Следующий узкий опыт по уточнению владельца — физическая зарядка у одной капсулы и доступные сигналы для выученного возврата (`docs/INFORMATION_AND_RETURN.md`); сети узлов пока нет.

**Продолжение исправления вращения:** версия 2 замыкает переход на реальном следующем решении вместо послесканового снимка. На 8 новых сценариях вращение — 5 окон против 46 у исходных весов и 26 у matched-контроля; посещено за сутки 119.5 клетки против 87.0 и 27.4. При этом после LAB-reset больше столкновений; полный критерий безопасности не выполнен, версия остаётся отдельным опытом. На карте владельца 4295 первый запуск даёт 4.77 m вместо 0.27 m за первые 300 шагов, но циклы ещё встречаются. См. [`docs/DECISION_TRANSITIONS.md`](docs/DECISION_TRANSITIONS.md).

## Что мы создаём

- **Не рельсовую игру со скриптовыми миссиями.** Мир и физика существуют независимо от представлений ИИ.
- **Один видимый герой на старте.** При необратимой гибели, если ресурсы позволяют, капсула готовит новую версию ровера на основе записанного опыта.
- **Сенсоры вместо всеведения.** Камера/визуальный канал, лидар, температура, свет, аккумулятор, ориентация, контакт, одометрия; карта строится из наблюдений и может деградировать из-за нехватки памяти.
- **Ограничения по-настоящему важны.** Заряд, тепло, время, память, связь, масса, кабели, вычисления, ресурсы и риск ошибок.
- **Обучение должно быть проверяемым.** Первый локальный агент, сохранение весов и сравнение на новых картах уже есть; надёжная адаптация к холоду, повреждениям и возврату ещё не доказана.
- **Постепенное развитие.** От навыка отъехать и вернуться до поиска льда, энергетики, связи, ремонта и производства.

**Уточнённый вектор:** медитативная песочница наблюдения за одним обучающимся ровером. Большая миссия — разведать далёкий крупный пласт, пригодный для добычи; отдельные льдинки и локальный рост концентрации лишь помогают поиску. Далее — самостоятельное обустройство с конечными ресурсами. Вектор и сюжет записаны в [`docs/DEPOSIT_SEARCH_VISION.md`](docs/DEPOSIT_SEARCH_VISION.md). В 0.2.0 готов первый стенд этой разведки; три разнесённые богатые пробы означают лишь LAB-кандидата, не доказанный запас воды или готовую добычу.

## Рабочий принцип

**Сначала маленькая проверяемая симуляция, потом новые возможности.** Не переписывать историю проекта при каждом появлении свежей идеи. Идеи дополняются, спорные решения заносятся в журнал, версии экспериментов воспроизводимы.

Визуальный ориентир — читабельный **2D top-down** с индустриальной выразительностью и ясными интерфейсами, по духу напоминающий *Factorio* и *RimWorld*, **без копирования их графики, кода или ассетов**.

## Чего в прототипе ещё нет

Нейроэволюции, кабельных/зарядных узлов, ремонтника, геолога, настоящего SLAM, радиосвязи, полной геофизики Луны, промышленности и полноценных сохранений мира. Ремонт, добыча воды и надёжное возвращение ещё не реализованы. Поиск использует условный поверхностный спектрометр, не геологическую модель подземного льда.

Комплектный мозг прежнего режима 0.2.0 перенесён из малого опыта: в двух тренировках по 80 эпизодов поздние версии уступили исходной на validation-картах, поэтому сохранена исходная версия E67704. Она часто повторяет пробы рядом со стартом. В 0.3.0 исследуется отдельный контроллер с новизной. Номер E и заполнение буфера не доказывают улучшение. Самостоятельный выбор удаления/сжатия памяти и фотографии ещё не реализованы; подробная карта пока вытесняет старые записи автоматически. Отпечатки знакомства занимают отдельный ограниченный ресурс и не восстанавливают бонус после вытеснения карты.

## Совместная работа

**Автор проекта управляет замыслом. Codex и ChatGPT — два помощника, работающих с одной историей изменений.** ChatGPT может добавлять идеи, документы и задачи, Codex — реализовывать, тестировать и документировать их. Доступ каждого определяется фактическими разрешениями подключённых инструментов. Не считать, что сообщение в чате автоматически изменяет репозиторий: изменение должно быть закоммичено и проверено.

Название — рабочее. Лицензия и публичность репозитория отдельно не определены; не публиковать проект или ассеты автоматически.
