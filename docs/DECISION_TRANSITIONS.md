# Последовательность наблюдений при обучении · LP-043

## Гипотеза до сравнения · 17.10.2026

В опытах с послесканированием TD-цель вычисляется по снимку `after`, хотя следующее решение получает другой снимок. На картах 42 и 4295 за 1200 действий: 400 послескановых снимков имеют `scanFresh=true`, а перед решением этот флаг всегда false. На 399 проверяемых границах отличается вход 10; также меняются температура, свет и заполненность карты. Значение Q для состояния со свежим сканом используется в цели, хотя сеть никогда не выбирает в нём действие и соответствующие входные веса не получают градиента от текущих состояний. Это подтверждённая несогласованность, но её вклад во вращение предстоит измерить.

Узкое изменение: сохранять незавершённый нетерминальный переход до следующего **реального** решения и замыкать его доступным тогда наблюдением. До выбора следующего действия обновление использует именно эти входы. Терминальный отказ не требует bootstrap и сохраняется до доступного питания, как прежде. Незавершённый нетерминальный переход при LAB-обрыве отбрасывается явно: нельзя подставлять начальное состояние нового мира. Спячка не выполняет вычислений. Карта, награда, действия, физика, replay 512, шаг обучения и gamma не меняются.

Отдельная версия политики `motion-dqn-v2` / schema 5 сохраняет архитектуру 61→32→5 и короткое окно. Перенос старой модели явный; старые модели, алгоритм и отчёты остаются историческими контролями. Экспорт весов не сохраняет незавершённый переход/replay/мир.

## Протокол decision-transitions-v1

- Исходные веса: комплектный `motion-dqn-v1`, E163378.
- Контроль `after` и исправление `decision`, два одинаковых тренировочных seed 1709/3011, по 80 эпизодов / 2400 шагов, карты 15001–15016; exploration 0.65→0.06.
- Validation: карты 16001–16003, learner seed 111/911. После выбора внутри групп по меньшему числу окон застоя/вращения, затем большему позднему посещению, затем меньшим отказам/столкновениям, открыть test: 17001–17004, seed 113/929.
- Каждая пара: 6 LAB-reset по 2400 шагов с переносом опыта и отдельная жизнь 43200 шагов без reset. Окна 300 шагов и определения вращения/застоя сохранены из прошлого аудита. Во всех этих проверках обучение включено.
- Три контроля: исходные веса со старым bootstrap, выбранная тренировка `after`, выбранная тренировка `decision`. Test не выбирает checkpoint. Карты 42/4295 — только диагностическое воспроизведение, без подбора по ним.
- Для продвижения: на validation и test у `decision` меньше и вращения, и объединённых проблемных окон, чем у обоих контролей; не меньше среднего посещения/покрытия за сутки; отключений не больше; столкновения не выше большего из 125% контроля и контроля +5. Иначе исправление остаётся отдельным опытом, без заявления об устранении зацикливания.

Протокол фиксируется до запуска. Отчёт хранит seed, выбранные веса, хеши и результаты всех групп. Отдельное пожелание владельца о плавных поворотах реализуется интерполяцией только в UI; поведение/скорость физики и результаты сравнения от FPS не зависят.

Согласование реального следующего наблюдения уменьшило вращение и общий застой, увеличило покрытие. Контроль с тем же дополнительным обучением деградировал. Это подтверждает полезность исправления в данном опыте; повторяемость проверена на двух тренировочных seed и новых картах, но не означает устранения всех циклов.

**Полный критерий продвижения не выполнен:** после reset существенно больше столкновений и больше отключений, чем у дообученного after-контроля. Его меньшее число разрядок сопровождается почти втрое меньшим покрытием, поэтому само по себе не означает лучшего поведения. Исправленный алгоритм доступен отдельной версией 2; основной профиль для новой установки не заменён. Память выбранного пользователем режима позволяет продолжать наблюдать выбранный опыт после обновления страницы. Поиск пласта и безопасная экспедиция ещё не освоены.

## Диагностическая карта владельца

После фиксации весов отдельно выполнен `npm run diagnose:sequential`, карты 42/4295, learner seed 71, 6 повторных LAB-запусков. На 4295 за первые 300 шагов первого запуска — **4.77 m вместо 0.27 m**; прежний мозг выполнял почти только повороты. У новой модели второй из шести запусков всё ещё содержит раннее вращение; на карте 42 — третий. Эти карты не выбирали checkpoint, случай не выдаётся за универсальное исправление.

Отчёт — [`../experiments/sequential-benchmark.json`](../experiments/sequential-benchmark.json), диагностика — [`../experiments/sequential-known.json`](../experiments/sequential-known.json). Сохранены обе выбранные модели, source/model SHA-256 и локальный подробный журнал с checksum. Старые motion/online-артефакты привязаны к проверенной исходной Git-ревизии, их результаты не переписаны под новый алгоритм.

`npm test`: **63/63**, включая реальную TD-цель на следующем наблюдении, LAB-обрыв без перехода в новый мир, отложенный отказ/сон, выключение обучения, детерминированные изменения весов, перенос моделей, неизменность физики при интерполяции и воспроизведение старта карты 4295.

## Плавное представление

Корпус интерполируется между физическими шагами; пауза/ручной шаг завершают картинку за 180 ms. Лучи сохраняют измеренные концы. Человек видит промежуточную позу, агент её не получает. На 1×–20× поворот плавный; на 1000× экран не показывает каждое действие. Принудительные повороты/паузы/движение в политику не добавлены.

Во время браузерной проверки выявлен старый JavaScript из HTTP-кэша. Для разработки используется `npm run dev` с `Cache-Control: no-cache`; исправлен Windows-путь корня сервера через `fileURLToPath`. Готовый опыт открыт на `http://localhost:8000/`, где загружены актуальные модули. Браузерные сохранения `localhost` и `127.0.0.1` отдельны; прежние веса на старом origin не удаляются.
