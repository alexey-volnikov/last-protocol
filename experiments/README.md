# Эксперименты

Первый реализованный опыт: [`../docs/WATER_EXPERIMENT.md`](../docs/WATER_EXPERIMENT.md). `npm run train:water` обучает локальную сеть; `npm run benchmark:water` повторяет оценку сохранённого мозга без обучения. В `water-benchmark.json` — протокол и агрегированные результаты, в `../models/water-dqn-v1.json` — веса. LAB-reset не является возрождением игрового ровера.

В Git хранить конфиги, манифесты и агрегированные метрики; большие журналы и модели — в локальном архиве/артефактах с ссылкой и checksum. Каждый опыт имеет seed, версию движка, модель, режим физики, лимиты памяти, энергию и наблюдения. Не делать выводов по одному удачному запуску.
