# Дорожная карта — от первого пикселя к автономной экспедиции

Этапы не гарантируют успех обучающего алгоритма. Каждый этап принимается только по проверяемым результатам.

## P0 · Концепция и первичная лаборатория (сейчас)

- [x] Единый реестр идей, протокол совместной работы, принципы честной симуляции.
- [x] Простейший 2D top-down просмотр, seed мира, один ровер, капсула, ограничения энергии/памяти и сенсоры (демо, не физически точная модель).
- [x] Изоляция наблюдений агента от полного состояния мира, слой отладки для человека.
- [ ] Повторяемый replay и полноценные долговременные сохранения (пока только живой журнал и reset).
- [ ] Показания реальных «виртуальных приборов» в удобной диагностике.

## P1 · Честная среда выживания

- [ ] Фиксированный time-step с эталонными тестами: энергия, тепло, день/ночь, взаимодействие со склонами/преградами.
- [ ] 0% → спячка; заряд ≥70% → пробуждение (с учётом температуры и доступа к солнцу).
- [ ] Отдельные RAM / карта / логи / вес модели; лимиты и политика удаления с последствиями.
- [ ] Имитация датчиков с шумами, SLAM/одометрический дрейф, неопределённость маршрута.
- [ ] Лог событий «ситуация → действие → результат» и диагностические графики.
- [ ] Один ремонтируемый вид повреждения со снижением скорости; ремонт у капсулы с затратами времени, энергии и материалов, без сброса опыта (LP-044).

## P2 · Первое настоящее обучение

- [ ] Проверить [предложение локального обучения](LOCAL_LEARNING_DESIGN.md): выбрать алгоритм и оценку, отделить версии мозга от физических отказов (D-013/014, LP-043).
- [x] Первый локальный обучаемый контроллер и отдельный LAB-процесс: MLP/Q-learning для поиска поверхностного льда, исходная эвристика сохранена как контроль (`WATER_EXPERIMENT.md`).
- [ ] Цель эксперимента: отъехать, изучить неизвестную область, вернуться, не потеряв питание и маршрут.
- [ ] Ближайший отдельный опыт LP-050: конечная контактная зарядка у одной капсулы и доступные маяк/подключение на входах сети; затем связать разведку с утратой подробной карты и проверить новую информацию без поощрения повторного обзора. `INFORMATION_AND_RETURN.md`. Переносные узлы идут после проверки возврата.
- [ ] Учёт опыта в течение жизни и между эпизодами; оценка обучения на *невиданных* seeds.
- [x] Сохранение версии модели и первый воспроизводимый benchmark поиска воды с необученной сетью, случайным контроллером и baseline; одного тренировочного seed недостаточно для устойчивого вывода.
- [ ] Несколько независимых тренировок, улучшение поиска без сигнала и проверка безопасного возвращения; первый поиск подтверждает лёд лишь на части новых карт.
- [x] Подготовить стенд D-016 / LP-045/046: далёкий пласт, локальная концентрация, ограниченный журнал, продолжение после находки и отдельный протокол (`DEPOSIT_LAB_PROTOCOL.md`, 0.2.0).
- [ ] Научить разведке в новом стенде: два запуска по 80 эпизодов не улучшили validation, на test 0/12 кандидатов. Проверить исследование новых областей и использование последовательных измерений; промышленную доступность пока не оценивать.
- [x] Подготовить отдельный опыт любопытства LP-028: признаки неизвестного из собственных сканов, ограниченные отпечатки, поощрение новых данных без повторного бонуса после вытеснения карты (`CURIOSITY_EXPERIMENT.md`, 0.3.0).
- [ ] Сбалансировать исследование с безопасностью и пробами: 0.3.0 увеличила покрытие, но получила 13 отключений против 12 и больше столкновений; кандидатов 0/16. Рост покрытия не считать освоенным поиском источника.
- [x] Проверить деградацию при включённом обучении: 72 сценария с LAB-reset и отдельной 24-часовой жизнью, семь вариантов, отдельный test. Исправлена потеря отложенного отказа; смешанная память дала частичный результат (`ONLINE_LEARNING_AUDIT.md`).
- [ ] Достичь устойчивого живого обучения: короткая история не подтвердила пользу, test 36 проблемных окон против 29 без доступа к истории и меньшее покрытие. Проверить физический смысл возврата, меру новой информации и горизонт оценки последствий отдельным протоколом, без ручной команды движения.
- [x] Реализовать и проверить отдельный LAB-контекст последних 32 действий из одометрии и измеренных последствий: 1 KiB RAM, перенос 49→61, четыре тренировки, 54 живых сценария и контроль с замаскированной историей. Улучшение не подтверждено (`MOTION_CONTEXT_EXPERIMENT.md`).
- [ ] Выбор удаления/сжатия подробных записей самим агентом с действительной потерей сведений и стоимостью обработки; фотографии пока не реализованы (LP-009/010).
- [ ] Проверить и документировать «стоимость размышления» / CPU budget.

## P3 · Энергосеть

- [ ] Инвентарь капсулы: панели, кабели, батареи с массой и количеством.
- [ ] Прокладка кабелей/узлы зарядки, ограничения длины и мощности.
- [ ] Автономные станции и решение о размещении узлов.

## P4 · Память, связь, отказоустойчивость

- [ ] Информационные узлы и ретрансляторы, локальная связь и энергозатраты.
- [ ] Бортовые бэкапы и передача телеметрии капсуле, потеря несинхронизированного опыта.
- [ ] Система ремонта / новых корпусов / последующих поколений с конечным материальным ресурсом.

## P5 · Несколько ИИ и расширение экспедиции

- [ ] Ремонтник-инженер со своей нейросетью, сенсорами, нуждами.
- [ ] Третий профиль агента: геолог (и/или координатор); согласовать дизайн.
- [ ] Координация, задачи, общая инфраструктура, реальные конфликты ресурсов.
- [ ] Поиск льда, бурение, извлечение воды.

## P6 · Лунная промышленность и игра

- [ ] Наблюдаемое самостоятельное обустройство: выбор вложений в энергию, ремонт, хранение и инструменты; развитие через физические возможности и обучение, не по номеру E (LP-048).
- [ ] Реголит, минералы, переработка, производство ограниченного набора изделий.
- [ ] Долгосрочная исследовательская миссия, человек на орбите (лор — после стабилизации симуляции).
- [ ] Сохранения, UX, визуал, доступность, оптимизация, тестовые миры, режимы скорости.

## Критерии «можно двигаться дальше»

Симулятор запускается с нуля; seed повторяем; сохранены тесты; физика не знает UI; агент не знает скрытые ресурсы; каждое улучшение обучения подкреплено сравнением с baseline.
