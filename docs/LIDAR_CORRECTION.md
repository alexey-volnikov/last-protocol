# Непрерывный луч лидара · LP-043 / D-025

## Гипотеза до изменения

17.10.2026: дискретный луч проверяет поверхность начиная с 0.35 m, затем через 0.32 m. Он может перескочить короткий участок каменной клетки рядом с углом. Например, карта 42, позиция (47.9367983945094, 32.108212741007335), курс 36.94000000000007 rad: свежий передний луч показывает 7 m, а движение блокируется. Это ошибка виртуального прибора, отдельная от способности сети учитывать видимую преграду.

Диагностика до исправления: фиксированный комплектный `motion-decision-dqn-v2`, карты 42/4295/17001–17004, seeds 113/929, epsilon 0.12, шесть LAB-попыток по 2400 шагов. 61 контакт: у 36 ближайший по курсу луч имел дальность ≥0.8 m, у 25 — <0.8 m. Это диагностика уже известных карт, не выбор модели и не оценка качества нового варианта.

Узкое изменение: вычислять первое пересечение луча с занятой клеткой/границей мира без пропусков между отсчётами. Частота, количество лучей, дальность, затраты энергии, действия и награда сохраняются. Прежний дискретный прибор доступен только как явно выбранный контроль `lidarMode: 'sampled-v1'`. Контроллер не получает карту или обходной маршрут.

## Критерий и протокол до запуска

Проверка геометрии: препятствие ближе 0.35 m, короткое пересечение угла, отрицательное/нулевое направление, граница мира, точное попадание в угол, отсутствие записи клеток за камнем. При отключённом сканировании сохраняются прежние показания; дополнительного бесплатного скана нет.

Независимое сравнение продолжающегося обучения с одинаковыми исходными весами E198828: прежний и исправленный прибор, карты validation 19001–19003 × seeds 127/937; затем единственный test 20001–20004 × seeds 131/941. Варианты не отбираются и не переобучаются по этим картам. В каждом случае шесть LAB-reset по 2400 шагов с общей ограниченной памятью, отдельно одна жизнь 43200 шагов с новой копией мозга. Epsilon 0.06, окно застоя 300 шагов, ≥100 активных действий; сон исключён. Это онлайн-адаптация, отдельного офлайн-обучения нет.

Критерий поведенческого улучшения, отдельно на validation и test: меньше суммарных столкновений, проблемных окон не больше; посещённые/наблюдённые клетки за жизнь и в последних трёх LAB-попытках ≥90% контроля; отключений не больше контроля. Если критерий не выполнен, публикуется отрицательный результат, исправление геометрии не объявляется освоенным объездом.

Совместимость: формат весов/schema 5 и 61 вход не меняются, импорт существующего мозга возможен, но последовательность показаний и последующее обучение меняются. Мир/replay всё ещё не сохраняются. Сводка получает идентификатор прибора; исторические результаты относятся к прежнему прибору и закрепляются за Git-ревизией до изменения. Новая версия симулятора 0.3.1.

## Реализация и результат

`src/sim/lidar.js` обходит пересечённые лучом клетки до первой скалы/границы. Память получает только отсчёты перед преградой и её измеренную клетку. Диапазон 7 m, 12 лучей, оплаченный скан каждые три физических шага сохранены. Лучи между сканами остаются старыми: поворот/движение могут сделать их недостаточными для следующего решения. Датчик контакта и выбор действий не менялись.

`npm run diagnose:lidar` воспроизводит известные случаи старого прибора (`lidar-diagnosis.json`), `npm run benchmark:lidar` — независимое сравнение (`lidar-benchmark.json`). Всего 28 сценариев, 196 отдельных запусков, 1 612 800 физических шагов; новые веса не выбирались и комплектная модель не заменялась. Все запуски с включённым обучением. Геометрические fixture-тесты проверяют ошибку отдельно от поведения.

| Показатель | Validation: старый → исправленный | Test: старый → исправленный |
|---|---:|---:|
| Столкновения после LAB-reset | 124 → 4 | 85 → 65 |
| Столкновения за отдельные жизни | 129 → 0 | 0 → 4 |
| Окна вращения | 37 → 36 | 11 → 13 |
| Вращение или застой | 47 → 48 | 22 → 24 |
| Посещено за жизнь, среднее | 109.0 → 80.5 | 95.1 → 87.1 |
| Наблюдено за жизнь, среднее | 883.7 → 756.5 | 789.8 → 735.3 |
| Отключения после LAB-reset | 36 → 36 | 48 → 48 |
| Отключения за жизни | 17 → 19 | 25 → 25 |

**Полный критерий не выполнен на обоих наборах.** Исправление убрало конкретную слепую зону, суммарных столкновений меньше, но устойчивый объезд и безопасная разведка не подтверждены: застой немного чаще, покрытие ниже. Кандидатов пласта нет. Корректный прибор используется в симуляции; изменение не объявляется улучшением всего мозга.

Старый `sequential-benchmark.json` закреплён за проверенной ревизией `8b4a1ca3fd3f87f29d5e081231a339096624d00f`; регрессии 4233/4295 явно используют прежний прибор. Старые агрегаты не пересчитаны и не выданы за результаты 0.3.1. Для полного воспроизведения прежних тренировок нужен их указанный исходный код. В новой сводке `status.lidarMode` различает приборы, schema сводки остаётся 4 с дополнительным полем. Окна нового сравнения хранятся локально в `experiments/runs/lidar-full.json`, checksum публичен.

В UI добавлены число контактов и последнее измерение по курсу, которое явно может устареть; версия 2 показывает новое сравнение. Прежние результаты других мозгов помечены историческими. Следующий узкий вопрос — как сеть использует уже видимую преграду и редкий опыт контактов. Отдельно остаются питание/возврат и физическая зарядка у капсулы (LP-050); готовые инструкции объезда/возврата не добавлены.
